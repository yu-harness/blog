## 我在做什么

计算机专业在读硕士，方向是大模型与 Agent 应用开发。平时主要在做 RAG、多 Agent 编排，以及 Agent 落地时的工程问题：工具调用的约束、上下文管理、评测与成本。

## 这里写什么

四个栏目，每篇只回答一个具体问题。

- **原理与边界**：模型在什么条件下会坏、代价是多少、实测下来是多少。token 与显存、上下文窗口、采样与幻觉、结构化输出的格式约定。
- **检索**：让模型用上外部知识。文档怎么切、向量怎么检索、结果怎么重排、效果怎么评，每篇配一次真实跑出来的数字。
- **Agent**：让模型自己动手。工具调用的格式约定、工具边界与权限约束、上下文与记忆、多角色编排与状态恢复。
- **实测与项目**：我自己搭过并且跑起来的东西。RAG 知识库问答、Coding Agent harness，写运行数据、参数取舍、故障怎么定位、哪一版最后被换掉了。

## 怎么写

三条规则，写不满就不发：

1. **每篇有一个可以复现的数字，或者一段能跑起来的代码。** 这是我唯一防得住复制的护城河，AI 生成的文章跑不出数字。
2. **不写"X 是什么"，不写"怎么用 X"。** 教科书和搜索已经把这些写完了。这里只写"X 在什么条件下会坏、代价是多少、我实测是多少"。
3. **每篇只落一个栏目，跨栏目的部分用标签标。** 标签是给读者横向找用的，比如"工具调用"这个标签下同时有格式约定和权限约束两篇。
